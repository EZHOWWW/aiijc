How to download text to cad datasets
Формат датасетов с текстом:
<path to datasets>/<dataset name>/\[category(optional)\]/models/<model name>.stl
<path to datasets>/<dataset name>/\[category(optional)\]/caption.json
caption.json:

```json
{
  "model_name": "description",
  # or
  "model_name": ["description 1", "description 2"]
}
```

# SadilKhan/Text2CAD

Это дополнение к abc_dataset.
В файлах text2cad_v1.1/text2cad_v1.1.csv и text2cad_v1.0/text2cad_v1.0.csv присудствуют две разметки от разных моделей. Нужно скачать только эти 2 файла из репозитория на hf.
Вот описание данных:
📌 text2cad_v1.1.csv (1.3GB)

    uid: Identifier (Same as DeepCAD).
    abstract: Abstract Level Annotation (Level 0).
    beginner: Beginner Level Annotation (Level 1).
    intermediate: Intermediate Level Annotation (Level 2).
    expert: Expert Level Annotation (Level 3).
    description (New): Description of the CAD Model generated by VLM.
    keywords (New): List of Keywords generated by VLM.
    all_level_data: All the level annotations generated by LLM before spliting.
    nli_data: The intermediate NLI response.

📌 text2cad_v1.0.csv (1.1GB)

    uid: Identifier (Same as DeepCAD).
    abstract: Abstract Level Annotation (Level 0).
    beginner: Beginner Level Annotation (Level 1).
    intermediate: Intermediate Level Annotation (Level 2).
    expert: Expert Level Annotation (Level 3).
    all_level_data: All the level annotations generated by LLM before spliting.
    nli_data: The intermediate NLI response.

Нужно сопоставить модели и их описание по uid который выглядит так: '0035/00359148'. Нужно сохранить все текстовые описания в таком формате caption.json так:

```json

"00359148*": ["Описание 1", "Описание 2"],
```

Типичное название модели в abc_dataset/models: 00353243_583d91aa6210ee1096566998_trimesh_044.stl где номер перед первым подчеркивание это uid после слеш. Нужно сопоставить по этому индодификатору.
